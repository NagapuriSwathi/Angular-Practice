## About

Angular Practice is a collection of exercises and small applications.

## Exercises

Angular Practice is a learn-by-doing project where I build practical exercises and small applications while developing my Angular and frontend development skills.

## Exercises

### Basic Calculator

- Accepts two positive numbers
- Provides an operation dropdown with
  - Addition (+)
  - Subtraction (-)
  - Multiplication (\*)
  - Division (/)
- Calculates and displays the result based on the selected operation

---

### Calculator UI Design

- A calculator interface focused on UI design and layout
- Built to practice structuring and styling a calculator interface
- No calculation functionality is claimed

---

### Geometry Measurement

- Provides measurement calculations for geometric shapes: rectangle, square, triangle, and circle
- Calculates both perimeter and area based on user-provided measurements
- **Rectangle:** Calculates perimeter and area using length and breadth
- **Square:** Calculates perimeter and area using the side length
- **Triangle:** Calculates perimeter and area using three side lengths
- **Circle:** Calculates circumference and area using the radius
- Displays the calculated result for each selected measurement

---

### Color Code Generator

- Generates a random color and displays its corresponding HEX color code
- Allows users to copy the generated HEX color code
- Provides RGB sliders to adjust Red, Green, and Blue color values
- Displays the resulting RGB color dynamically based on the selected slider values
- Allows users to copy the generated RGB color value
- Includes a color picker for selecting colors interactively

---

### Reviews Page

- Displays user reviews in a structured card-based layout
- Shows user profile images, names, roles, ratings, and review comments
- Uses JSON data to manage and display the review information
- Dynamically renders multiple review entries from the data source
- Demonstrates how structured data can be used to populate reusable UI elements

---

### Counter

- Displays a numeric counter value
- Provides an **Increment** button to increase the counter value
- Provides a **Decrement** button to decrease the counter value
- Provides a **Reset** button to return the counter to its initial value
- Demonstrates interactive UI updates based on user actions

---

### Product Quantity Selector

- Displays multiple products with their individual prices
- Allows users to increase or decrease the quantity of each product
- Calculates the total price for each product based on its selected quantity
- Updates quantities and totals dynamically based on user interactions
- Demonstrates interactive product selection and real-time price calculations

---

### Employee Directory

- Displays employee information in a structured table
- Shows employee name, department, role, and employment status
- Uses JSON data to manage the employee records
- Dynamically renders employee data in a tabular format
- Demonstrates working with structured data and data-driven UI rendering

---

### Registration Form

- Implements an Angular **Template-Driven Form** for user registration
- Includes fields for full name, email, password, confirm password, date of birth, and account type
- Validates required fields including full name, email, password, confirm password, and account type
- Validates that the **Confirm Password** value matches the **Password**
- Requires users to accept the Terms and Conditions before registration
- Demonstrates form validation and user input handling in Angular

---

### Random Tools

#### Random Number Generator

- Accepts a minimum and maximum number as user inputs
- Generates a random number within the specified range
- Displays the generated random number to the user
- Provides a button to generate a new random number
- Demonstrates user input handling and random number generation

#### Random Name Generator

- Generates a random name when the user clicks the generate button
- Displays the generated name dynamically
- Provides a simple interactive interface for random name generation

#### Random Image Generator

- Generates a random image when the user clicks the generate button
- Displays the generated image dynamically
