# Angular Practice

A collection of interactive Angular practice projects and mini applications built to practice and demonstrate frontend web development skills.

## Projects

### Basic Calculator
An interactive calculator demonstrating UI interaction, event handling, and calculation logic.

### Calculator UI
A calculator interface focused on responsive UI design and component-based development.

### Geometry Measurement
An interactive tool for calculating geometric measurements like perimeter and area of various shapes like Rectangle, Square, Triangle and Circle.

### Color Code Generator
A color utility for generating and working with color codes.

### Technologies Used
- Angular
- TypeScript
- HTML
- CSS
